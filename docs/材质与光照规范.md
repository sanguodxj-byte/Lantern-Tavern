# 材质与光照规范

本规范用于 Lantern Tavern 的体素环境、场景道具和动态火光，目标是保留漫反射、阴影和明暗层次，禁止材质受火光照射时出现白色镜面倒影或无来源泛白。

## 非金属环境材质

- 酒馆墙、地板、天花板、柱、门、吧台和普通体素道具必须使用 `specular_disabled`。
- `StandardMaterial3D` 非金属材质必须使用 `SPECULAR_DISABLED`，`metallic = 0.0`，`roughness >= 0.75`。
- 自定义 Shader 必须同时满足两层保护：`render_mode` 包含 `specular_disabled`，并在 `fragment()` 中显式写入 `SPECULAR = 0.0`。
- 旧资源中保留的 `specular` 参数只允许作为兼容字段，不得参与最终输出。

## 场景光源

- 酒馆光照档案必须对场景中的全部 `Light3D` 设置 `light_specular = 0.0`，包括 `DirectionalLight3D`、`OmniLight3D` 和后续新增的光源类型。
- 火把和蜡烛仍使用漫反射照亮环境；不得通过添加补光灯、关闭 `unshaded` 或移除阴影来掩盖高光问题。
- 自发光火焰、粒子和魔法材质是视觉发光源，不等同于环境材质反射；它们的 `emission` 可以保留，但不能重新开启环境镜面高光。

## 地牢材质与火把

- 地牢墙、地面、天花板、门、台阶、撤离点和普通装饰统一视为环境材质：使用 `specular_disabled`、`metallic = 0.0`、`roughness >= 0.75`。
- 地牢地形 Shader 必须在 `render_mode` 禁用镜面，并在 `fragment()` 中显式写入 `SPECULAR = 0.0`；兼容用的 `specular` uniform 固定为 `0.0`。
- 地牢动态火把、烘焙火把、烛台和玩家视野灯的 `Light3D.light_specular` 必须为 `0.0`。运行时初始扫描和后续 streaming 动态注册都必须执行该收束。
- 火把必须保留原有漫反射、实时阴影、`omni_range` 和 `light_energy` 约束；禁止添加补光源、关闭漫反射或删除阴影解决高光/黑块问题。
- 金属武器不属于地牢环境材质规范；武器材质继续由装备材质适配器保留其有意的金属表现。

## 新增/修改检查

1. 先确认材质是否为金属或明确的自发光特殊材质；普通木、石、砖、蜡、布和骨骼材质默认走非金属规范。
2. 检查 Shader 的 `render_mode` 和 `SPECULAR` 输出，不能只调单个材质实例的数值。
3. 检查所属场景的所有光源是否经过场景光照档案，不能只处理触发亮斑的那一盏灯；地牢还要检查 streaming 后注册的光源。
4. 用真实 3D 酒馆或地牢截图检查台面/墙面、地板、道具、火把和阴影；禁止使用 `unshaded` 截图作为材质验收依据。
5. 修改共享 Shader 或光照档案时，必须更新 gdUnit4 回归测试，至少覆盖材质高光关闭和全部光源高光关闭两项。
