## 1. 装备定位与双轨获取机制

在《Dungeon Tavern》中，装备是玩家白天的核心战斗保障。防具提供被动生存能力与负重，武器则直接决定伤害类型与技能释放权限。

### 1.1 装备获取渠道
*   **野外遗迹搜刮（常规产出）**：白天在地下城关卡探索时，玩家搜刮**"古代遗迹宝箱"**、**"棺椁陪葬品"**或**"冒险者残骸"**时，能直接获得带有随机词缀的常规装备。野外的普通杂鱼怪物被击杀时，**绝对不会掉落人类装备**，仅掉落酿酒原材料或换钱古玩。
*   **夜晚酒馆消费抵扣与赠予（极品/盲盒产出）**：
    *   顾客生成时采用**金币/装备互斥双轨携带机制**（详情参见 `12-满意度与价格结算系统.md`）。有一半的怪物顾客来店时未携带发光铁片，但随身携带了一件准备喝爽后赠予老板的随机装备。
    *   对人类顾客，因钱不够会拿随身装备抵扣酒钱；对怪物顾客，在喝爽到极点（爆表）且未携带发光铁片时，会狂热地将随身携带的装备赠予老板（系统后台统一计入盲盒抵账）。
    *   **纯随机盲盒机制**：获得（抵扣或赠予）的装备品质、阶位、词缀完全是**全局装备库纯随机抽取**，与当前的势力声望高低无任何概率关联。

> 所有关于伤害的修正一律使用**百分比形式（如 +10% 伤害、+5% 暴击率）** 或**暴击/防御/负重等面板项**呈现；命中已恒为真（见 05），**不再有任何"命中率/闪避率"类修正**。

## 3. 生成框架：材质 × 稀有度（掉落随机，成形即固定）

装备实例在**生成（怪物 / 宝箱 / 赠予出现的同一瞬间）**由以下两轴随机定型，成形后属性固定不可更改（对齐 §0 硬规则 1、①）：

### 3.1 材质阶梯（Material Tiers，对齐 ToME4 / Elona）
材质决定基础坚固度、负重系数与固有材质特质；**按地牢深度（Zone）Zone 锁定可生成的材质**（见 §4 深度阶位锁）。

| 材质名称 | 对应层级 (Zone) | 基础面板加成 | 重量系数 | 特殊固有材质属性 |
| :--- | :--- | :--- | :--- | :--- |
| **木/皮 (Wood/Leather)** | Zone 0 (序章) | **0%** 基础 | **0.6x** (极轻) | 钝击抗性低，易燃 |
| **铁质 (Iron)** | Zone 0 ~ 1 | **+0%** 标称 | **1.0x** (标准) | 基础沉稳 |
| **钢质 (Steel)** | Zone 1 ~ 2 | **+5%** 面板 | **1.1x** (略重) | 耐久度提升，防磨损 +10% |
| **玄铁/陨铁 (Meteoric)** | Zone 2 ~ 3 | **+10%** 面板 | **1.2x** (重) | 附带 +2% 暗/暗影伤害 |
| **秘银 (Mithril)** | Zone 3 ~ 4 | **+15%** 面板 | **0.7x** (轻盈) | 破甲 +3%，法力消耗 -2% |
| **精金/龙骨 (Adamantite/Dragonic)** | Zone 4 ~ 5 | **+20%** 面板 | **1.3x** (沉重) | 物理防御 +2，全减伤 +2% |

### 3.2 品质稀有度阶层（Quality Rarity Tiers）
稀有度决定 UI 显示颜色、**词缀插槽数量（Affix Slots）**与面板系数浮动：

| 稀有度阶层 | UI 显示颜色 | 词缀插槽规则 | 面板系数浮动 |
| :--- | :--- | :--- | :--- |
| **劣质 (Inferior)** | 灰色 (`#888888`) | 强制含 **1 负向前缀** | **0.85x ~ 0.95x** |
| **普通 (Common)** | 白色 (`#FFFFFF`) | **0 词缀** | **1.00x** |
| **优秀 (Superior)** | 绿色 (`#33FF55`) | 必含 **1 正向前缀** | **1.02x ~ 1.05x** |
| **稀有 (Rare)** | 蓝色 (`#3399FF`) | 必含 **1 正向前缀 + 1 后缀** | **1.05x ~ 1.08x** |
| **史诗 (Epic)** | 紫色 (`#AA33FF`) | 包含 **2 正向前缀 + 1 后缀** | **1.08x ~ 1.12x** |
| **神器 (Artifact)** | 金黄色 (`#FFCC00`) | 专属材质 + **2 赐福前缀 + 1 顶级后缀** | **1.15x (固定顶峰)** |

> **完整命名示例**：`[材质前缀] + [稀有度前缀] + [前缀] + [基础装备] + [后缀]` → 如"粗糙的 秘银 铁质长剑 之 斩杀"。前缀以定语形式附加在装备原名前；后缀独立成词。

## 4. 实体真实掉落与深度阶位锁

### 4.1 实体真实掉落（Physical Entity Drop）

> **核心规则（对齐 §0 硬规则「随机分两层」）**：
> - **属性层（生成即固定）**：完整配装（**武器 + 防具 + 副手/盾 + 辅助挂件，全槽位**）在 **怪物 / 宝箱生成的同一瞬间** 即由全局生成器一次性定型（§3 的材质 × 稀有度 → 词缀插槽与面板系数，并受 §4.2 深度阶位锁约束）。怪物 / 宝箱**持有**这份已生成的配装。
> - **掉落层（死亡 / 开启时的独立概率事件）**："掉落"是把已持有实例转移给玩家，**绝不在怪物死亡或宝箱开启时另行随机生成属性**；但是否掉落、掉落哪一件，是**死亡 / 开启那一瞬的概率判定**（详见下方「人形怪物掉落」「宝箱同生生成」），且该判定**只能从已穿戴 / 已填充的槽位中抽取，永不凭空爆出怪物未持有的类型 / 槽位装备**。

*   **人形怪物拥有完整槽位，但槽位未必填满；掉落为概率事件且只从"已穿戴"抽取**：所有**人形怪物**在生成时均拥有**正常的装备槽位与武器槽位**（主手武器 + 副手/盾 + 防具 + 辅助挂件），各槽位按 §3 材质×稀有度 + §4.2 阶位锁生成对应实例——**但"有槽位"不等于"槽位一定填充"**：每个槽位按设定 / 概率可能留空，空槽位不贡献任何掉落物。被击杀时：
    *   **先按掉落概率判定是否掉落**（对齐 §0 ②，死亡瞬间的独立概率事件）；
    *   **若判定掉落，再从怪物"当前实际穿戴（非空槽位）的装备"中随机选取一件或多件**作为掉落物，且保留战斗中造成的磨损与初始词缀；
    *   **严禁**在怪物死亡时调用随机装备池凭空爆出怪物未穿戴的类型 / 槽位装备——掉落集合严格 ⊆ 怪物生成时持有的实例集合。
*   **宝箱同生生成**：环境宝箱（Chests）、石棺（Sarcophagus）、遗迹祭坛在生成（刷入地图）的瞬间，其内含装备已由上一步生成器定型；玩家开启只是取出已生成的实例，**不触发二次随机**。
*   **无凭空爆装（含属性与类型）**：地图上不存在"死亡后随机爆装（新生成属性）"或"开启时现摇"的环节。**唯一发生在死亡 / 开启时刻的随机，只是对已生成实例的"掉落与否 / 掉落哪件"概率抽取（§0 ②），绝不生成新属性或新类型**——所有属性的随机都封死在生成时刻（§0 ①）。

### 4.2 阶位与层级深度强相关（Tier-Depth Hard Lock）
装备阶位（由 §3 材质/稀有度生成的强度）必须严格受地牢层级（`zone` / `depth`）限制，彻底禁止前期爆出高阶神兵：

| 地牢层级区域 (Zone) | 允许生成的最高阶位 (Tier) | 阶位概率分布 (Tier Weights) | 描述说明 |
| :--- | :--- | :--- | :--- |
| **Zone 0 (地牢一层 / 序章)** | **Tier 0** | Tier 0: **100%**, Tier 1: **0%**, Tier 2: **0%** | 绝不可能出现二阶/三阶武器 |
| **Zone 1 (幽暗森林)** | **Tier 0 ~ 1** | Tier 0: **80%**, Tier 1: **20%**, Tier 2: **0%** | 极小概率出现二阶初步武器 |
| **Zone 2 (地下矿洞)** | **Tier 0 ~ 1** | Tier 0: **50%**, Tier 1: **50%**, Tier 2: **0%** | 中级层级，过渡装备 |
| **Zone 3 (古老墓园)** | **Tier 1 ~ 2** | Tier 0: **20%**, Tier 1: **60%**, Tier 2: **20%** | 开始解锁三阶稀有装 |
| **Zone 4 (火山遗迹)** | **Tier 1 ~ 2** | Tier 0: **0%**, Tier 1: **50%**, Tier 2: **50%** | 深层地牢，高阶占比大 |
| **Zone 5 (废墟底座 / 终极层)** | **Tier 2** | Tier 0: **0%**, Tier 1: **20%**, Tier 2: **80%** | 顶级神兵层级 |

> Tier 与 §3 材质的映射：Tier 0 ≈ 木/铁，Tier 1 ≈ 钢/玄铁，Tier 2 ≈ 秘银/精金，并受 Zone 材质可用性共同约束（§3.1）。

## 6. 品质磨损 5 级阶梯 + 鉴定 / 诅咒 / 赐福

> **取代旧耐久度**：原 `06 §4.1` 的"点数耐久度（5% 概率 -1 点、归零即损坏）"已**废除**，统一改为本节的 **5 级品质阶梯概率退阶**模型（对齐《Barony》硬核体系，信息密度更高）。

### 6.1 装备品质阶梯与动态退阶磨损系统（Quality Scale）
装备采用 **5 级品质阶梯**（取代旧点数耐久）：

| 品质阶梯名称 | 属性效果系数 | 视觉与状态表现 | 退阶与损毁判定 |
| :--- | :--- | :--- | :--- |
| **Excellent (完美)** | **100%** 全面板属性 | 装备表面无瑕，带微光特效 | 攻击/受击有小概率退阶至 Serviceable |
| **Serviceable (完好)** | **90%** 属性面板 | 正常战斗痕迹 | 概率退阶至 Worn |
| **Worn (磨损)** | **75%** 属性面板 | 显现切口与划痕 | 概率退阶至 Decrepit |
| **Decrepit (破损)** | **50%** 属性面板 | 严重龟裂，性能大跌 | 概率退阶至 Destroyed |
| **Destroyed (碎坏)** | **0%**（装备粉碎销毁） | 彻底毁坏，自动解装备 | 物品直接从背包/装备栏中永久消失 |

**动态磨损概率公式（Degradation Chance）**：在发生近战攻击、举盾防守受击或受到强酸/火焰陷阱侵蚀时，系统触发退阶判定：
$$\text{退阶判定概率 } P_{\text{degrade}} = P_{\text{base}} \times \left(1 - \frac{\text{相关武器/格挡技能等级}}{100}\right)$$
*   $P_{\text{base}}$：基础退阶率（普通攻击默认为 **3%**，格挡重击为 **8%**，强酸液体侵蚀为 **20%**）。
*   **熟练度减损**：随着技能等级提高，退阶概率大幅下降。
*   **100 级传说特权（Legendary Perks）**：当对应的武器/防盾技能达到 **100 级** 时，$P_{\text{degrade}} = 0$，实现**永不磨损（Never Degrade）**！

### 6.2 鉴定、诅咒与赐福系统（Appraisal, Curse & Blessing）
*   **鉴定机制（Unidentified）**：在地牢中掉落的装备/卷轴默认为未鉴定状态，隐藏真正的品质与赐福/诅咒属性，名称显示为泛称（如"古旧的剑"、"神秘的袍子"）。
    *   **盲目盲穿风险**：玩家可以在未鉴定状态下强行装备，但若该装备带有诅咒，将立刻陷入诅咒锁定。
    *   **鉴定途径**：① 使用【鉴定卷轴】；② 提升【鉴定技能】（感知 PER 越高看破成功率越高）；③ 酒馆 NPC 付费批量鉴定。
*   **诅咒机制（Cursed）**：
    *   **锁定解卸（`is_cursed = true`）**：一旦将带诅咒的装备穿到身上，该装备槽位被**强行锁定，绝对无法手动卸下或替换**！
    *   **惩罚效应**：全面板属性降低 **30%**；每 5 秒持续扣除玩家少量法力值或生命值。
    *   **解除诅咒手段**：① 使用【净化卷轴】；② 酒馆教堂圣职者付费净化；③ **硬核磨损**：持续使用该诅咒装备，直至其磨损至 **Destroyed（碎坏）** 粉碎，自动解除槽位锁定。
*   **赐福机制（Blessed）**：
    *   **增幅效应（`is_blessed = true`）**：被赐福的装备基础属性面板获得 **+50% 额外提升**！
    *   **防磨损加成**：退阶判定概率降低 50%。

### 6.3 玩法协同逻辑
$$\text{装备实际效能} = \text{基础属性} \times \text{品质阶梯系数 (0.5 \sim 1.0)} \times \text{稀有度系数 (§3.2)} \times \begin{cases} 1.5 & (\text{Blessed 赐福}) \\ 0.7 & (\text{Cursed 诅咒}) \\ 1.0 & (\text{Normal 普通}) \end{cases}$$
1.  **富有人性与贪婪的决策选择**：地牢掉落未鉴定装备时，玩家需要抉择是冒着"穿上诅咒装备锁定脱不下来"的风险立刻盲穿，还是忍耐存放到找到鉴定卷轴/回酒馆后再鉴定。
2.  **磨损与装备循环**：避免了装备永久不坏导致的底层物资过剩，形成"战斗磨损退阶 → 地牢修理 → 酒馆铁匠维保"的健康经济循环。

## 7. 装备维保与装甲熟练度被动特权

### 7.1 装备维保与修复（Repair）
*   **地牢局内**：使用【磨刀石】或【修理卷轴】，可将降低品质的装备提升一个阶梯（最高至 Serviceable）。
*   **酒馆大本营（Tavern）**：寻找铁匠 NPC 消耗金币与金属材料，可将装备完全打磨恢复至 **Excellent（完美）** 状态（参见 `07-员工系统.md`）。由于员工为自愿服务的无偿雇员，修理仅需消耗少量的基础木材或铁矿石，免收任何金币手续费。

### 7.2 装甲熟练度阶梯被动特权（Proficiency Perks Matrix）
为对齐 `05-战斗系统.md` §5.2，当玩家通过在野外被击中承伤来累积各防具熟练度等级时，将逐层解锁专属的永久被动加成（闪避以**性能档位**呈现，不再使用已移除的闪避率%）：

#### A. 轻型装甲熟练度被动（Light Armor Tiers）
*   **【一阶轻装被动：轻盈步法 / Light Footwork】**：穿着轻型铠甲时，**闪避性能额外 +1 档（i-frame 更长）**。
*   **【二阶轻装被动：侧身闪避 / Sidestep】**：穿着轻型铠甲时，**闪避性能额外 +2 档，且侧击与背击对玩家造成的伤害加成降低 50%**。
*   **【三阶轻装被动：疾风闪跃 / Gale Evasion】**：穿着轻型铠甲时，**闪避性能额外 +3 档，受到的暴击率降低 5%，且成功闪避怪物的物理攻击后，自身下一次攻击前摇降低 15%**。

#### B. 重型装甲熟练度被动（Heavy Armor Tiers）
*   **【一阶重装被动：装甲加固 / Reinforced Armor】**：穿着重型铠甲时，**最终物理防御值额外 +2**。
*   **【二阶重装被动：冲击缓冲 / Impact Cushioning】**：穿着重型铠甲时，**最终物理防御值额外 +5%，且受到物理攻击时有 20% 的概率使装备防具不扣减品质阶梯**。
*   **【三阶重装被动：不屈壁垒 / Unyielding Bastion】**：穿着重型铠甲时，**最终物理防御值额外 +10%，完全免疫任何战术击退效果（无法被击退），且每次承受物理伤害有 15% 的概率对攻击者产生真实反震伤害，反震数值等同于自身物理防御力的 50%**。

## 8. 数据结构与结算公式（data/weapons.json & Inventory）

为支持本系统，每个装备实例需包含以下数据字段：

```json
{
  "id": "iron_longsword",
  "name": "铁质长剑",
  "category": "Sword",
  "weapon_type": "one_handed_sword",
  "tier": 1,
  "material": "IRON",
  "rarity": "COMMON",
  "base_damage_dice": "2D6",
  "base_damage_flat": 8,
  "quality_tier": "EXCELLENT",
  "is_identified": false,
  "is_cursed": false,
  "is_blessed": false,
  "affixes": ["sharp", "of_slaying"]
}
```

**词缀结算**（`DamageResolver.gd` / `CombatBridge.gd` / `equipment_loadout.gd` 中解析 `affixes` 数组）：
*   伤害/暴击层：`sharp`(+3% 伤,+1% 暴)、`flamereached`(+3% 火伤)、`blessed`(+4% 伤,+2% 暴)、`rusty`(-4% 伤) 直接计入 `damage_mult`；`bloodthirsty`(+0.5% 吸血) 在实际伤害 >0 时回复 $\max(1, \lfloor D_{\text{deal}} \times 0.005 \rfloor)$ HP；`cursed_vampiric`(+5% 伤, 自扣 1 HP) 攻击瞬间强制扣 1 HP 并锁定槽位；`of_slaying`(+5% 低血伤害) 当目标 HP ≤25% 时 ×1.05。
*   格挡/防御层：`sturdy`(物防+1)、`cracked`(物防-1)、`of_tenacity`(残血物防+2) 直接加减最终物理防具值；`of_parrying`(格挡扣损+4%) 在完美格挡/盾牌受击减伤时额外 +4%。
*   探险/磨损层：`brittle`(磨损率+15%)、`sturdy`(磨损率-10%) 修改 $P_{\text{degrade}}$ 基准；`shining`(照亮+1m) 动态更新玩家 `OmniLight3D.omni_range += 1.0`。
