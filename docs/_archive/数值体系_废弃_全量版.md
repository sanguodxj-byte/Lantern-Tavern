> **用途**：汇集 Lantern Tavern 项目内**已决定**的全部数值、常数与公式，作为后续平衡、实现、测试的单一真相源。
> **来源标注**：每条数值标注其出处——
> - `【代码】` = 已在 GDScript 中硬编码的常量（运行时真实生效）；
> - `【文档】` = 仅在策划文档中写明、尚未常量化到代码的值（设计意图）；
> - `【冲突】` = 代码与文档不一致，需拍板对齐。
> 凡标注 file:line 的，均为 `【代码】` 实证位置。

## 2. 战斗公式（Combat）

全部来源：`globals/combat/damage_resolver.gd`（已硬编码）。

### 2.1 命中与伤害主流程
- **命中**：hitbox 重叠即命中，无投骰。
- **骰子均值（无伤害 RNG）**：`dice_avg = dice_count × (sides+1) / 2.0` `:260`
- **原始伤害**：`raw = (dice_avg + weapon_flat + stat_flat) × weapon_damage_mult` `:271`

### 2.2 暴击
- **暴击率**：`crit_rate = 5.0 + attacker.per×0.5 − defender.per×0.5 + crit_bonus`，下限 **0** `:198-199`
- **暴击倍率**：`crit_mult = 1.5 + attacker.per×0.01 − defender.per×0.01 + crit_damage_bonus`，下限 **1.1** `:206-207`
- **暴击硬直**：0.5s（近战/远程）`:242`

### 2.3 防御结算
- `final_def = armor_def + con` `:226`
- 无视防御：`final_def *= max(0, 1 − ignore_def_percent/100)` `:230`（战锤被动可置 0 `:228`）
- `after_def = base_damage − final_def`，**伤害下限 1**

### 2.4 朝向加成
- **背刺**：`backstab_mult = 1.5`（剑被动 +0.3 → **1.8**）`:212-215`，判定 `dot > 0.5`（cos60°）
- **侧击**：`dot < 0.3`，加成 ×1.05 `【文档】`

### 2.5 战斗风格倍率（STYLE_META）

| 风格 | 攻速倍率 | 移速倍率 | 其他 |
|---|---|---|---|
| ONE_HAND（基础） | 1.0（默认） | 1.0（默认） | — |
| ONE_HAND_SHIELD | 0.95 | 0.95 | 格挡减伤 0.15 |
| TWO_HAND | 0.85 | 0.9 | 伤害 ×1.0，击退力 4.0 |
| DUAL_WIELD | 1.2 | 1.0 | 副手伤害 60% |
| UNARMED | 1.3 | 1.1 | — |
| RANGED | 0.9 | 0.95 | — |
| SPELL | 0.9 | 0.95 | — |

`【代码】damage_resolver.gd:24` 起（`STYLE_META`）。

### 2.6 动量 / 冲击伤害
- 冲击伤害 `compute_physical_impact_damage`：`damage_pct = 0.06 + ratio×0.24`，最低速度 4.0 / 满速 14.0 `:175`
- 动量上限（`momentum_context.gd`）：`MOMENTUM_CAP 10.0` / `DAMAGE_BONUS_CAP 0.3` / `KNOCKBACK_BONUS_CAP 0.8` / `ACCELERATION_WEIGHT 0.15`
- **木桩/劈砍**：wood chop +50%（×1.5）；skeleton smash +40%（×1.4）`【代码】`

### 2.7 闪避 / i-frame（仅技能）

- 仅技能提供 i-frame：滑铲冲刺 **0.5s**（`action_skills.gd:72`）；战术滑步 **0.3s**（`action_skills.gd:86`）。

### 2.8 基础时序
- 基础攻击间隔 `BASE_ATTACK_INTERVAL = 1.0`；基础移速 `BASE_MOVE_SPEED = 5.0` `combat_engine.gd:33-34`

  - 生死之交 1501+：×2.0 / ×2.0 / 40%
- 好感→声望：`floor(affinity_delta × 0.1)`（`tavern_settlement.gd:229`）
- 常客名册上限 `REGULAR_MAX_PER_RACE 5`；熟识解锁 `individual_affinity ≥ 30`
- 人类结算声望：禁忌风味拒付 `rep −10`；贵价 `rep −2`；暴利 `rep −15`
- 怪物结算好感：极佳 +15 / 满意 +10 / 一般 +2 / 不合 −5
- 声望赠礼池：普通 80% / 稀有 20%（`randf()<0.2` 判稀有）

### 7.2 酿造（【代码】brewing_data.gd）
- 16 种核心口味（Flavor 枚举）；40 种材料 `MATERIALS_DB`（每条含 zone + 风味强度 1–4）
- 10 种经典酒谱 `RECIPES_DB`：亮莓果汁 30 / 月光艾尔 45 / 熔岩蜂皇威士忌 80；其余种族专属酒 `price: null`
- 6 种族口味阈值 `RACE_PREFERENCES`（人类：麦香≥2&甜美≥1，禁忌恶臭/腐败/死寂/剧毒；哥布林：腐败≥2&甜美≥1，禁忌苦涩；牛头人：麦香≥3&浓郁≥2，禁忌酸爽；独眼巨人：辣口≥3&温暖≥2，禁忌甜美；幽灵：死寂≥3&寒凉≥2，禁忌温暖；精灵：香醇≥3&果香≥2，禁忌恶臭/腐败）
- 合成：`compute_brew_flavors` = 各材料风味 × 数量加和；满意度 = 喜爱全达标 && 讨厌全 0
- 时序（【文档】docs/03、11）：发酵周期 1 整天；陈酿每 +1 天全风味 +1（上限 3 天）；环境共振仅发酵第 1 天有效
