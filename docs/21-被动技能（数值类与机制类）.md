## 一、流派专精被动（武器流派限定 · 17 项 = 6 流派 × 2 + 徒手专属 5）

> 仅当以对应手部握持流派姿态作战时激活（部分还需满足副手/装备条件）。来源：`31-流派与武器扩展技能设计方案.md` §一。

### 1.1 单手流派 `ONE_HAND`
- **决斗者** `passive_style_onehand_duelist`：准星持续指向单一敌人并长按右键 3 秒后锁定目标；锁定期间仅针对该目标获得 +50% 攻击力、+50% 暴击率、+50% 闪避率。准星离开敌人立即失效，切换目标需重新长按 3 秒。
- **奥法之剑** `passive_style_onehand_spellblade`：主手单手且副手空置时，右键可呼出/打开魔法选择界面；近战满蓄力攻击释放时，自动无前摇同时释放选中的魔法（消耗对应法力/冷却）。

### 1.2 持盾流派 `ONE_HAND_SHIELD`
- **盾击** `passive_style_shield_bash`：格挡状态下按左键使用盾牌攻击造成轻微击退；若在敌人攻击后 0.3s 内盾击命中，造成 3 秒压制（压制期间敌方无法行动且防御抗性视为 0）。
- **折射** `passive_style_shield_refraction`：防御远程和法系攻击时，盾牌耐久消耗加倍，但会将攻击效果 100% 原路反射回对方。

### 1.3 双手流派 `TWO_HAND`
- **蓄势** `passive_style_twohand_accumulation`：双手握持蓄力挥砍时不会被普通受击打断前摇，且蓄力期间受到的伤害降低 30%；蓄力期间承受的伤害会转化为释放时的追加伤害。
- **重型挥舞** `passive_style_twohand_heavy_swing`：改变基础攻击动作，替换为大范围的大弧度横扫骨骼动画动作，扩展攻击的扇形覆盖角度与碰撞半径。

### 1.4 双持流派 `DUAL_WIELD`
- **交错挥砍** `passive_style_dual_cross_strike`：主手攻击后 0.5s 内副手攻击命中目标，副手必定暴击；副手攻击后 0.5s 内主手攻击命中目标，主手无视 50% 防御。攻击落空即断开连携，且触发/断开后 3 秒内无法再次触发。
- **十字返** `passive_style_dual_cross_counter`：受到敌人近战攻击前摇瞬间同时按下左右键，使用双刃交叉架住敌方武器打断其攻击，并瞬间自动执行一次左右手同时挥砍反击。

### 1.5 徒手流派 `UNARMED`
> ⚠️ **徒手无武器、无武器专精**（原 doc31 §二「拳肉相搏 / 潜行扣抓」已移除）。为补偿「无武器骰子 / 材质 / 词缀 / 武器专精 scaling」的缺失，徒手以 **5 项专属被动**特别对待（其余 6 流派各 2 项）。

- **暴风骤雨** `passive_style_unarmed_flurry_storm`：左右手交替的徒手攻击每次减少 5% 攻击冷却，最高可减少 60%，持续 3 秒。
- **过肩摔** `passive_style_unarmed_over_shoulder_slam`：左右键同时按住 5 秒后对距离 0.25m 以内的目标释放；对普通敌人造成 100% 最大生命值真实伤害，对精英/Boss 造成 25% 最大生命值真实伤害，并对周围 5m 所有敌人造成等额伤害。
- **擒拿** `passive_style_unarmed_grapple`：左右键同时按下，可对**生命值 ≤ 30% 的普通怪物**执行抓取，**效果完全等同于主动技能「投掷」**（将其抓起砸向地面 / 四周，造成投掷撞击伤害 6 + 击退 5.0，见 `enemy.gd:404`）。
- **迅猛踢击** `passive_style_unarmed_swift_kick`：将主动技能「踢击」视为**普通攻击**——其冷却改为受 **武器冷却**（§2.5.2）影响；普通攻击的全部加成（属性、暴击、背刺、词缀等效）与伤害（**等同于左右键的普通徒手攻击**）对其生效。
- **折箭术** `passive_style_unarmed_arrow_break`：徒手攻击可对**远程投射物**生效；攻击命中投射物时使其**折射**至其他方向（偏转角度由实现决定，建议 ±60°~90° 随机）。

### 1.6 远程流派 `RANGED`
- **看破弱点** `passive_style_ranged_weakpoint_sight`：举弓/举弩准星指向敌人身体持续满 1.5 秒后，目标身上的红色弱点标记显现；射中弱点标记必定造成致命爆头暴击（伤害 ×2.0）。
- **贯穿** `passive_style_ranged_piercing`：弩和满弓射出的弹道可以贯穿至多 5 个敌人，每贯穿一个敌人递减 20% 伤害。

### 1.7 法系流派 `SPELL`
- **奥术护盾** `passive_style_spell_arcane_barrier`：每次施放法术消耗的蓝量直接转化为等额护盾，并且该护盾可以无限叠加。
- **元素环** `passive_style_spell_elemental_ring`：施放法术后，周围生成跟随自身的元素环（持续 5s），近战敌人靠近时自动挂载对应法力的燃烧/冰冻状态。

## 二、通用被动（无流派限制）

### 2.1 坚韧 `tenacity`
- **类型**：常驻恢复 / Sustain
- **效果**：每 5 秒自动恢复 2% 最大生命值（`HealAmount = max(1, round(MaxHP × 0.02))`）。
- **触发**：挂载后常驻生效，按 5 秒 Tick 触发治疗。
```json
"tenacity": {
  "id": "tenacity",
  "name": "坚韧",
  "type": "passive",
  "school": "any",
  "effect_type": "periodic_heal",
  "interval_sec": 5.0,
  "heal_max_hp_pct": 2.0,
  "desc": "每 5 秒恢复 2% 最大生命值。"
}
```

### 2.2 汲取 `siphon`
- **类型**：战斗吸血 / Combat Lifesteal
- **效果**：造成伤害的 10% 转化为自身治疗（`lifesteal_amount += round(final_damage × 0.10)`），集成于 `DamageResolver` / `CombatBridge` 阶段五。
- **触发**：造成伤害时触发。
```json
"siphon": {
  "id": "siphon",
  "name": "汲取",
  "type": "passive",
  "school": "any",
  "effect_type": "lifesteal",
  "lifesteal_percent": 10.0,
  "desc": "吸取造成伤害的 10% 治愈自身。"
}
```
