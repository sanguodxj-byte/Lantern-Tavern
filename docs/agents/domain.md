# Domain docs

This repository uses a single domain context.

Before exploring domain code, read root `CONTEXT.md` when present and any relevant decisions in `docs/adr/`. Their absence is allowed; proceed without creating placeholders.

Use the vocabulary in `CONTEXT.md` and `docs/术语表.md`. The terminology table is the current semantic source of truth for UI and item-interaction terms. Surface conflicts with an existing ADR instead of silently overriding it.
