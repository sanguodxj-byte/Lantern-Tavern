# 35 - 护甲体系

> **设计权威**：本文档为护甲系统的设计权威，代码为占位符，冲突时以本文档为准。
> 参照系：PoE2 / Brotato 家族的**伤害相关百分比减伤**模型，废弃旧版平减法。

---

## 一、设计目标

| 目标 | 说明 |
|---|---|
| 防御对小/中伤有效 | 低伤被显著吸收，高伤按比例穿透 |
| 元素抗性独立于物理防御 | 火/冰/雷/毒各有独立抗性轴 |
| 轻甲 vs 重甲取舍 | 轻甲 = 闪避+机动；重甲 = 减伤+抗退 |
| 熟练度成长 | 穿甲受击累积经验，解锁专属被动 |
| 品质/材质/词缀联动 | 护甲防御力受品质系数、材质倍率、词缀修正三重影响 |

## 三、物理减伤公式

### 3.1 核心公式（废弃平减法）

```
def = (Σ armor_phys_def + con) × (1 − ignore_def_percent / 100)
mitigation% = def / (def + k × base_damage)      # k = 8（可调 6~12）
mitigation% = min(mitigation%, 0.90)              # 硬封顶 90%
post_mit = base_damage × (1 − mitigation%)
flat_reduce = Σ 里程碑绝对减免（厚实皮肤 −2、元素护壳 −4 等）
final_damage = max(1, round(post_mit − flat_reduce))
```

**关键特性**：
- `base_damage` = 进入防御前的伤害（已含暴击/朝向/材质修正）
- 减伤随伤害大小自适应：小伤吸收多、大伤穿透多
- `max(1)` 下限保留，伤害永不归零
- `k` 常数控制防御边际收益曲线陡峭程度

### 3.2 参考减伤表（k=8，def = Σ armor_phys_def + con）

| 场景 | def | base | 减伤% | 实收 |
|---|---|---|---|---|
| 轻甲 vs 小伤 | 20 | 20 | 33.3% | 13 |
| 中甲 vs 普攻 | 40 | 50 | 9.1% | 45 |
| 重甲 vs 普攻 | 80 | 50 | 16.0% | 42 |
| 重甲 vs 小伤 | 80 | 20 | 33.3% | 13 |
| 任意甲 vs Boss 巨伤 | 60 | 200 | 3.2% | 193 |
| 高甲 vs 普攻（堆到顶） | 120 | 50 | 23.1% | 38 |

### 3.3 品质系数 × 材质倍率 × 稀有度系数

护甲的**实际物理防御值**由三层修正叠加：

```
eff_armor_phys_def = base_armor_phys_def
    × quality_coefficient(quality_tier)       # EXCELLENT=1.0, SERVICEABLE=0.9, WORN=0.75, DECREPIT=0.5
    × material_multiplier(material_tier)       # wood=0.9, iron=1.0, steel=1.05, meteoric=1.10, mithril=1.15, adamantite=1.20
    × rarity_coefficient(rarity)               # INFERIOR=0.85, COMMON=1.0, SUPERIOR=1.03, RARE=1.06, EPIC=1.10, ARTIFACT=1.15
```

元素抗性同样受品质系数影响，但不受材质/稀有度修正（材质/稀有度仅作用于物理防御基值）。

## 四、元素抗性体系

### 4.1 四系元素抗性

| 抗性 | 作用对象 | 结算方式 | 上限 |
|---|---|---|---|
| 火焰抗性 `armor_fire_res` | 火属性法术/陷阱/词缀 | 绝对减伤（post-mit 后） | 无硬上限，但装备来源受限 |
| 冰霜抗性 `armor_ice_res` | 冰属性法术/陷阱 | 绝对减伤 | 同上 |
| 雷电抗性 `armor_lightning_res` | 雷属性法术/陷阱 | 绝对减伤 | 同上 |
| 毒素抗性 `armor_poison_res` | 毒属性法术/陷阱/DOT | 绝对减伤 | 同上 |

**结算顺序**：物理减伤（§3）→ 元素抗性绝对减免 → 里程碑绝对减免 → `max(1)`。

### 4.2 魔法减伤百分比

```
armor_magic_res_percent 作用于所有 attack_type == "spell" 的伤害
magic_mitigation = Σ armor_magic_res_percent（全身累加）
magic_mitigation = min(magic_mitigation, 75.0)  # 硬封顶 75%
spell_damage = base_spell_damage × (1 − magic_mitigation / 100)
```

**与元素抗性的关系**：
- 魔法减伤先结算（百分比），元素抗性后结算（绝对值）
- 一件法术伤害 = 先吃魔法减伤%，再吃元素抗性绝对值

### 4.3 击退抗性

```
knockback_res = Σ armor_knockback_res（全身累加）
knockback_res = clamp(knockback_res, 0.0, 1.0)
effective_knockback = base_knockback × (1 − knockback_res)
```

重甲天然附带击退抗性；轻甲默认为 0。

## 六、护甲熟练度系统

### 6.1 熟练度累积

- **触发条件**：穿着对应类型护甲时被敌人物理攻击命中（无论是否格挡）
- **累积方式**：每次被命中 +1 熟练度经验（格挡命中 +2）
- **等级阶梯**：Lv.1 → Lv.100，每 10 级解锁一阶被动（T1/T2/T3）

### 6.2 轻型装甲熟练度被动

| 阶梯 | 名称 | 解锁等级 | 效果 |
|---|---|---|---|
| T1 | 轻盈步法 / Light Footwork | Lv.10 | 穿轻甲时闪避性能 +1 档（i-frame 更长） |
| T2 | 侧身闪避 / Sidestep | Lv.30 | 穿轻甲时闪避性能 +2 档；侧击/背击伤害加成降低 50% |
| T3 | 疾风闪跃 / Gale Evasion | Lv.60 | 穿轻甲时闪避性能 +3 档；被暴击率 −5%；成功闪避后下次攻击前摇 −15% |

### 6.3 重型装甲熟练度被动

| 阶梯 | 名称 | 解锁等级 | 效果 |
|---|---|---|---|
| T1 | 装甲加固 / Reinforced Armor | Lv.10 | 穿重甲时最终物理防御 +2 |
| T2 | 冲击缓冲 / Impact Cushioning | Lv.30 | 穿重甲时最终物理防御 +5%；受物理攻击 20% 概率不扣品质阶梯 |
| T3 | 不屈壁垒 / Unyielding Bastion | Lv.60 | 穿重甲时最终物理防御 +10%；完全免疫击退；15% 概率真实反震（= 自身物防 50%） |

### 6.4 熟练度查询接口

```
ArmorProficiency.get_level(armor_type: String) -> int
ArmorProficiency.has_perk(armor_type: String, perk_id: String) -> bool
ArmorProficiency.is_wearing_type(armor_type: String) -> bool  # 检查当前是否穿着至少一件该类型护甲
```

## 九、护甲磨损（受击退阶）

### 9.1 触发条件

- 被物理攻击命中（无论是否格挡）
- 受到强酸/火焰陷阱侵蚀

### 9.2 退阶概率

```
P_degrade = P_base × (1 − armor_proficiency_level / 100)

P_base:
  普通受击 = 3%
  格挡重击 = 8%
  强酸侵蚀 = 20%
```

### 9.3 磨损效果

品质阶梯降低时，护甲的 `eff_armor_phys_def` 和元素抗性按系数衰减：

| 品质 | 系数 | 物防效果 | 元素抗性效果 |
|---|---|---|---|
| EXCELLENT | 1.0 | 100% | 100% |
| SERVICEABLE | 0.9 | 90% | 90% |
| WORN | 0.75 | 75% | 75% |
| DECREPIT | 0.5 | 50% | 50% |
| DESTROYED | 0.0 | 自动解装备 | 自动解装备 |

### 9.4 重甲不磨损特权

重甲 T2 被动「冲击缓冲」：受物理攻击 20% 概率不扣减品质阶梯。
